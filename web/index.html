How it works

From agent call to provable record, in one hop

0001

Your agent calls a tool

Claude Code, Claude Desktop, or any MCP client calls a tool, prompt, or resource — authenticated by a scoped API key, resolved straight to your tenant.

0002

The gateway writes the event

The call is written once to the event chain, hash-linked to the event before it, before the result is returned to your agent.

0003

Anyone verifies the chain

Check integrity via /v1/events/verify or the dashboard's Chain Integrity card — valid, broken (with the exact event), or empty.

What's live today

Built for systems where "trust me" isn't good enough

0004

Hash-chained verification

Every event chained by hash. Full recheck on manual verify; refreshes run an incremental pass against a stored checkpoint sub-second instead of rescanning the whole chain.

0005

Tenant isolation

Projects, API keys, agents, and events are scoped to a tenant at the database layer. Cross-tenant reads fail closed — not just hidden in the UI.

0006

MCP gateway

Speaks Tools, Prompts, and Resources natively. Connect Claude Code or any MCP client with one command and a scoped API key.

0007

Role-based access

Owner, Admin, and Member roles, auto-provisioned on upgrade. Only an Owner can touch billing, retention, or the danger zone.

0008

Usage & self-serve billing

Per-tenant quotas and retention by plan, enforced at ingest. Upgrade through Stripe Checkout — no sales call, no manual approval.
