🚀 Getting Started: Send your first event

To see the platform in action, try sending a test event using one of your API keys. Copy and run the command below in your terminal:

curl -X POST {{.BaseURL}}/v1/events \
  -H "Authorization: Bearer YOUR_API_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{"event_type": "test.first_event"}'

Expected Response (201 Created)

{
  "event": {
    "id": "evt_...",
    "project_id": "proj_...",
    "tenant_id": "{{.Tenant.ID}}",
    "sequence": 1,
    "event_type": "test.first_event",
    "actor_id": "",
    "payload": {"event_type": "test.first_event"},
    "hash": "...",
    "occurred_at": "...",
    "created_at": "..."
  }
}

Common Issues

  • 401 Unauthorized: Check if your API Key is correct and active.
  • 403 Forbidden: Key needs ingest scope.
  • 400 Bad Request: event_type is required in body.
  • 429 Too Many: Quota exceeded for your plan.
